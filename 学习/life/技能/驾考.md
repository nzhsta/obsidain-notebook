# 5 行驶规则
- 没有划分机动车道、非机动车道和人行道的
	- 机动车在道路中间通行，**非机动车和行人在道路两侧通行**。
- **无.城3公4**，**有.城5公7**
	- **无**道路中心线的道路，**城**市道路为每小时**30**公里，公路为每小时**40**管理
	- **有**道路中心线的道路，**城**市道路为每小时**50**公里，公路为每小时**70**管理
- 以下情况速度不得超过30公里/时：
	1. 进出非机动车道，通过铁路道口、急弯路、窄路、窄桥时
	2. 掉头、转弯、下陡坡时
	3. 不良天气能见度低于50米时
	4. 在冰雪、泥泞的道路上行驶时
	5. 牵引发生故障的机动车时
- 在有中心点的路口左转弯时要靠路口中心点左侧转弯
- 高速公路最低车速：
	- 两条车道是：100 60 （左边100，右边60）
	- 三条车道是：110 90 60 （左边110，中间90，右边60）
	- 四条车道是：110 90 90 60
- 让行原则
	- 转弯车辆让直行车辆先行
	- 右方道路来车先行
	- 右转弯车让左转弯车辆先行


| 场景       | 考点                       | 速记      |
| -------- | ------------------------ | ------- |
| **跟车距离** | 车速>100km/h，车距≥100m       | 100-1原则 |
|          | 车速<100km/h，车距≥50m        | 50起步    |
| **恶劣天气** | 雾/雨/雪：减速+开近光+雾灯+危险灯      | 减速+开灯   |
|          | 能见度<200m：限速60km/h，车距 100 | 261口诀   |
|          | 能见度<100m：限速40km/h, 车距 50 | 145口诀   |
|          | 能见度<50m：限速20km/h，尽快驶离    | 52离口诀   |
| **爆胎处理** | 松油门+稳方向+轻点刹+驶离车道         | 不踩急刹    |
| **制动失效** | 降挡+拉手刹+撞摩擦物减速            | 逐级降挡    |
| **水滑现象** | 缓抬油门+减速，不可急刹             | 水滑=缓抬油  |

# 6 车灯

- 夜间没有路灯、照明不良或者遇到有雾、雨、雪、沙尘、冰雹等**低能见度**情况下行驶时
	- 应当开启前照灯、示廓灯和后位灯，
	- **但是！同方向行驶的后车与前车近距离行驶时，不得使用远光灯。**

- 机动车**雾天**行驶应当开启**雾灯**和**危险报警闪光灯**.
- **夜间**通过急弯、坡路、拱桥、人行横道或者没有交通信号灯控制的路口时
	- 应当**交替使用远近光灯**示意。

  - 变更车道时
	  - 应当提前开启转向灯
	  - 夜间还需变换使用**远、近光灯或者鸣喇叭**示意
- 150米以外会车时改用近光灯

| 场景       | 正确操作                        | 速记       |
| -------- | --------------------------- | -------- |
| **灯光使用** | 夜间会车：150米外换近光               | 150=近光   |
|          | 雾天：开雾灯+近光+危险灯               | 雾=三灯齐开   |
|          | 故障停车：开危险灯+示廓灯               | 停车=双灯    |
|          | 转弯/变道：提前3秒打灯                | 3秒预告     |
| **起步顺序** | 一踩（离合）二挂（挡）三转向（灯）四喇叭 五松（手刹） | 口诀：踩挂转喇松 |
| **高速变道** | 一次变更一条车道，提前3秒打灯             | 一条道+3秒   |
