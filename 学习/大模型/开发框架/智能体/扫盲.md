# 1 Langchain 相关 
## 1.1 FewShotPromptTemplate

`FewShotPromptTemplate` 的本质就是：**把"怎么选样本"和"样本怎么格式化"分开，然后自动组装**
### 1.1.1 代码解析

```python
FewShotPromptTemplate(
    prefix=prefix,                                    # 前缀提示词
    suffix=suffix,                                    # 后缀提示词（通常放用户输入位置）
    example_prompt=intent_example_prompt,             # 示例格式化模板
    example_selector=example_selector or get_example_selector(embeddings),  # 示例选择器
    example_separator="\n\n",                         # 示例分隔符
    input_variables=["intentions", "query"],          # 输入变量
    output_parser=IntentionCheckParse(),              # 输出解析器
)
```

### 1.1.2 核心特点

**使用 `example_selector` 而非 `examples`**

| 对比项  | examples  | example_selector |
| ---- | --------- | ---------------- |
| 用途   | 固定示例列表    | 动态选择相关示例         |
| 特点   | 所有示例都传给模型 | 根据输入从大量示例中选最相关的  |
| 适用场景 | 示例少、固定    | 示例多、需要语义匹配       |

### 1.1.3 完整使用示例

```python
from langchain.prompts import FewShotPromptTemplate, PromptTemplate
from langchain.prompts.example_selector import SemanticSimilarityExampleSelector
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Chroma

# 1. 定义示例模板
intent_example_prompt = PromptTemplate(
    input_variables=["intentions", "query", "answer"],
    template="""意图列表: {intentions}
用户问题: {query}
模型回答: {answer}"""
)

# 2. 定义示例池
examples = [
    {"intentions": "['天气', '时间']", "query": "今天杭州热吗", "answer": "杭州今天25度，天气晴朗"},
    {"intentions": "['音乐', '娱乐']", "query": "放首歌听听", "answer": "为你播放流行音乐"},
    {"intentions": "['导航', '出行']", "query": "去机场怎么走", "answer": "全程约40分钟，建议走高架"},
    # ... 更多示例
]

# 3. 创建示例选择器（基于语义相似度）
example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples=examples,
    embeddings=embeddings,           # 嵌入模型
    vectorstore_cls=Chroma,          # 向量数据库
    k=3                              # 每次选择3个相关示例
)

# 4. 构建 FewShotPromptTemplate
prefix = "你是一个意图检查助手"
suffix = "意图列表: {intentions}\n用户问题: {query}\n模型回答:"

few_shot_prompt = FewShotPromptTemplate(
    prefix=prefix,
    suffix=suffix,
    example_prompt=intent_example_prompt,
    example_selector=example_selector,
    example_separator="\n\n",
    input_variables=["intentions", "query"],
    output_parser=IntentionCheckParse(),
)

# 5. 格式化 prompt
result = few_shot_prompt.format(
    intentions="['天气', '音乐', '导航']",
    query="外面冷不冷"
)

# 6. 结合 LLM 使用
from langchain.chat_models import ChatOpenAI
chain = few_shot_prompt | ChatOpenAI()
response = chain.invoke({
    "intentions": "['天气', '音乐', '导航']",
    "query": "外面冷不冷"
})
```

### 1.1.4 工作流程图

```
用户输入 "外面冷不冷"
        ↓
   example_selector 语义匹配
        ↓
从示例池选择最相关的 3 个示例
        ↓
组合 prefix + 示例 + suffix
        ↓
生成完整 prompt → LLM → 意图检查结果
```

### 1.1.5 输出解析器作用

```python
class IntentionCheckParse(BaseOutputParser):
    """解析 LLM 返回的意图检查结果"""
    
    def parse(self, text: str) -> dict:
        # 将 LLM 输出转换为结构化数据
        # 例如：提取意图、判断是否匹配等
        return {"matched": True, "intent": "天气"}
```
