### 1. 大模型架构与原理（2 周→精通）
| 主题 | 要掌握到的深度 | 验证标准 |
|---|---|---|
| Transformer 全家桶 | 手写 Multi-Head Attention、RoPE、ALiBi、RMSNorm；知道 LLaMA/GPT 每一层维度、参数量计算公式 | 30 min 内无参考写出 LLaMA 一个 Block 的 PyTorch 代码，参数量估算误差 <5% |
| 位置编码 & 长度外推 | 理解 RoPE 旋转角频率、NTK-aware、YaRN、LongRoPE 差异 | 能解释为什么 100k context 需要调整 base 频率 |
| MoE/稀疏化 | 了解 Switch-Transformer、DeepSeek-MoE 的门控机制、Expert 数量选择、负载均衡 loss | 给出 8×7B MoE 实际激活参数量计算式 |

### 2. 预训练/后训练全流程（3 周→可独立跑通 1B 模型）
| 阶段 | 关键技能 | 掌握深度 |
|---|---|---|
| 数据工程 | 清洗→去重→混合比例→token 分布校准 | 用 `datatrove`/`wudao` 复现 1B token 清洗脚本，能解释为什么中文需要 0.3× 英文比例 |
| 预训练 | 分布式策略：张量并行（TP）、流水线并行（PP）、Zero-3、DDP+FlashAttention2；学会在 8×A100 上把 1B 模型训练到 1.5T token 无 OOM | 用 `deepspeed`+`llama-recipes` 跑通 1B 模型，会调 `ds_config.json`，能解释 `activation_checkpointing` 省显存原理 |
| SFT | LoRA/QLoRA/DoRA、packing、conversation template、mask 掉 user prompt | 在 `openchat-3.5-7b` 上 1 小时复现 52k 数据微调，eval 提高 >2% |
| RLHF | PPO、DPO、KTO、SimPO；理解 KL 约束、reward model 过拟合信号 | 用 `trl` 跑通 DPO，能画出 reward/kl 曲线并解释震荡原因 |
| 评估 | 掌握 Eleuther `lm-eval-harness`，知道如何自定义中文 benchmark；理解 contamination 检查 | 提交一次 PR 到 harness 新增中文任务 |

### 3. 推理与部署（1 周→线上可灰度）
| 主题 | 深度要求 |
|---|---|
| 量化 | GPTQ vs AWQ vs KV-cache INT8 差异；7B 模型 4-bit 量化后显存≈3.6 GB，能算对；会写 `bitsandbytes` 自定义量化 kernel 调用 |
| 并行推理 | `vLLM` 的 PagedAttention 原理，能画出 block table；用 `tensorrt-llm` 把 7B 模型 TP=2 部署到 2×A10，首 token 延迟 <300 ms |
| 服务化 | FastAPI+uvicorn 写流式 generate，支持 `n`>1 的 beam search；会写 OpenAI-compatible API，压测 QPS>20 |

### 4. 大模型特有 Trick（面试高频，1 天/条）
| 问题 | 必须答到的点 |
|---|---|
| 长度外推失败怎么调 | 先换 RoPE base→再 YaRN→再 LongLoRA→最后 NTK-RoPE 插值 |
| 微调后灾难遗忘 | 混合 5% 预训练数据 + Learning Rate 3e-5→2e-5 退火 + Cosine 重升温 |
| 训练出现 loss spike | 检查 gradient clipping、warmup step、data shuffle seed、tokenizer 版本 |
| 千亿模型显存估算 | 参数+梯度+优化器状态+KV-cache+activation：1B≈16 GB（fp16+Adam），会口算 |
