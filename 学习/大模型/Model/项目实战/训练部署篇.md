# 1. embedding model验证和转换
![image.png](https://learning-1316972768.cos.ap-nanjing.myqcloud.com/%E5%AD%A6%E4%B9%A0/largeModel/20251001155638039.png)
> [!attention] 模型选择
> 
- 模型分两种
	- 以 `sentence` 结尾的模型——<span style="background:rgba(2, 170, 11, 0.55)">sentence transformer</span>格式（**推荐**）
	- 不跟 `sentence` 的模型——huggingFace transformer格式（基本格式）
- 结构
  ```shell
  text2vec-base-chinese-sentence/ 
  ├── 0_Transformer/ 模型结构
  ├── 1_Pooling/ 一般sentence-transformer带有
  ├── 2_Normalize/ 归一化层
  ├── config.json 
  ├── config_sentence_transformers.json 
  ├── modules.json 
  └── pytorch_model.bin
  ```
	一般带有 polling 层的都是 sentence-transformer。
	Embedding_model 通常情况是<font color="#00b050">自带有归一化层</font>的。一般可以通过 Normalize 目录或者 modules. Json 来判断是否准确包含归一化层，或者判断<font color="#00b050">它的模长是否接近 1</font>。如果未包含归一化层，则需要<font color="#c00000">手动转换</font>添加。
	- 手动添加方法
		```python
		import numpy as np 
		from sentence_transformers 
		import SentenceTransformer,models 
		model_path = r"D:\PycharmProjects\demo_15\embedding_model\sungw111\text2vec- base-chinese-sentence" 
		bert = models.Transformer(model_path) 
		# 添加缺失的归一化层 
		pooling = models.Pooling(bert.get_word_embedding_dimension(), pooling_mode='mean') 
		normalize = models.Normalize()
		# 组合完整模型 
		full_model = SentenceTransformer(modules=[bert, pooling, normalize]) p
		rint(full_model) 
		save_path=r"D:\PycharmProjects\demo_15\embedding_model\zy\text2vec-base-chinese- sentence" 
		full_model.save(save_path) 
		# 加载修复后的模型 
		model = SentenceTransformer(r"D:\PycharmProjects\demo_15\embedding_model\zy\text2vec- base-chinese-sentence") 
		# 验证向量归一化 
		text = "测试文本" 
		vec = model.encode(text) 
		print("修正后模长:", np.linalg.norm(vec)) # 应输出≈1.0
		```
